# Educational Promo Page

A small static HTML/CSS learning project presenting technology training content and links.

## Files
- `index.html` — page markup and links
- `css/` — styles
- `images/` — visual assets
- `error.html` — placeholder file

## Run locally
Clone or download this repository and open `index.html` in a browser. No backend is required.

## Notes
The page references third-party educational brands, images and links. It is a **practice project**, not an official website for those organizations. Rights for any redistributed images should be checked before reuse.

## Portfolio classification
Frontend development practice (HTML and CSS). Not a primary research portfolio item.
